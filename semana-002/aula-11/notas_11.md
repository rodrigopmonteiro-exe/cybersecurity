## Comandos comuns em pseudocódigo

| Comando | Finalidade |
|---|---|
| INÍCIO | Começar o algoritmo |
| LEIA | Receber informação |
| ESCREVA | Apresentar informação |
| ← | Atribuir valor |
| FIM | Encerrar o algoritmo |


# Parte 2 — Exemplos (25 minutos)

## Exemplo: somar dois números.

```text
ALGORITMO Soma

INÍCIO

    LEIA numero1
    LEIA numero2

    resultado ← numero1 + numero2

    ESCREVA resultado

FIM ```

# Parte 4 — Laboratório Python (25 minutos)

Transforme o primeiro pseudocódigo em Python:

```python
print("SOMA DE TRES NUMEROS")

n1 = float(input("Numero 1: "))
n2 = float(input("Numero 2: "))
n3 = float(input("Numero 3: "))

resultado = n1 + n2 + n3

print("Resultado:", resultado) ```
