# 1. O QUE É UM ALGORITMO?

Um algoritmo é uma sequência organizada, lógica e finita de instruções que devem ser executadas para resolver um problema ou realizar uma tarefa.

Em palavras simples: um algoritmo é um passo a passo para chegar a um resultado.

Todo algoritmo básico pode ser compreendido por três etapas:

- Input: entrada.
- Processing: processamento.
- Output: saída.

Essa estrutura é conhecida como IPO (Input, Processing, Output).

## 1.1 Exemplo cotidiano

Preparar um café:

1. Pegar uma xícara.
2. Aquecer a água.
3. Colocar o pó no filtro.
4. Despejar a água.
5. Servir o café.

Um computador executa instruções de maneira semelhante, mas precisa que elas sejam especificadas formalmente.

---

# 2. O QUE É PENSAMENTO COMPUTACIONAL?

É a capacidade de analisar um problema, dividi-lo em partes menores e construir uma sequência lógica de passos para encontrar uma solução.

**Atenção:** pensamento computacional não significa apenas saber programar.

Você pode utilizá-lo para:

- Resolver problemas do cotidiano.
- Organizar tarefas.
- Analisar situações.
- Desenvolver sistemas complexos.

## 2.1 Os quatro pilares fundamentais

### 1. Decomposição

Dividir um problema complexo em problemas menores e mais fáceis de resolver.

**Exemplo:**

Para desenvolver um sistema de segurança, dividir o trabalho em:

- Autenticação.
- Controle de acesso.
- Armazenamento.
- Monitoramento.

### 2. Reconhecimento de padrões

Identificar características que se repetem em diferentes problemas.

**Exemplo:**

Perceber que várias tentativas de login apresentam o mesmo comportamento suspeito.

### 3. Abstração

Ignorar informações desnecessárias e concentrar-se nos detalhes importantes.

**Exemplo:**

Ao analisar uma tentativa de invasão, concentrar-se em:

- Endereço IP.
- Horário.
- Usuário.
- Comportamento da conexão.

### 4. Algoritmos

Criar uma sequência organizada de instruções para resolver um problema.

**Exemplo:**

Desenvolver um programa que identifica tentativas de acesso com senhas incorretas.

---

# 3. PENSAMENTO COMPUTACIONAL NO COTIDIANO

Imagine que você precisa desenvolver um novo sistema de segurança.

Os quatro pilares podem ser aplicados da seguinte maneira:

- **Decomposição:** separar a construção em tarefas menores, como cadastro, autenticação e controle de acesso.
- **Reconhecimento de padrões:** identificar padrões comuns de acesso e comportamentos suspeitos.
- **Abstração:** concentrar-se nos detalhes essenciais para o funcionamento e a segurança do sistema.
- **Algoritmos:** criar etapas organizadas para construir e executar o sistema.

Essa aplicação demonstra como o pensamento computacional pode ajudar na resolução de problemas reais de tecnologia.

---

# 4. DIFERENÇA ENTRE ALGORITMO E PROGRAMA

Um algoritmo é uma sequência lógica de instruções para resolver um problema, enquanto um programa é a implementação desse algoritmo em uma linguagem de programação para que o computador possa executá-lo.

Em resumo:

- **Algoritmo:** descreve a solução.
- **Programa:** implementa a solução em código executável.

Um programa pode implementar um ou vários algoritmos.

---

# 5. CINCO CARACTERÍSTICAS FUNDAMENTAIS DE UM BOM ALGORITMO

- **Clareza:** as instruções devem ser compreensíveis.
- **Precisão:** cada instrução deve indicar exatamente o que fazer.
- **Ordem lógica:** as etapas devem seguir uma sequência coerente.
- **Finitude:** o algoritmo deve terminar após uma quantidade finita de etapas.
- **Resultado definido:** deve produzir um resultado esperado a partir dos dados de entrada fornecidos.

# 6. EXERCÍCIOS RESOLVIDOS

## Exercício 1 — Cite três algoritmos utilizados no cotidiano.

### A) Preparar um café

1. Pegar uma xícara.
2. Ferver a água.
3. Colocar o pó no filtro.
4. Despejar a água.
5. Servir o café.

### B) Sacar dinheiro em um caixa eletrônico

1. Inserir o cartão.
2. Digitar a senha.
3. Escolher a operação.
4. Informar o valor.
5. Retirar o dinheiro.

### C) Calcular o troco de uma compra

1. Informar o valor da compra.
2. Informar o valor pago.
3. Subtrair o valor da compra do valor pago.
4. Apresentar o troco.

**Fórmula:**

Troco = Valor pago - Valor da compra

## Exercício 2 — Organize cinco etapas para calcular a média de três notas.

1. **Início:** começar o algoritmo.
2. **Entrada:** solicitar ao usuário três notas.
3. **Processamento:** somar as três notas e dividir o resultado por três.
4. **Saída:** exibir a média calculada.
5. **Fim:** encerrar o algoritmo.

**Fórmula matemática:**

Média = (Nota 1 + Nota 2 + Nota 3) / 3

## Exercício 3 — Por que a ordem das instruções é importante?

Porque um algoritmo precisa executar as etapas em uma sequência lógica e organizada para produzir o resultado correto.

Cada instrução depende, muitas vezes, da anterior.

Exemplo:

1. Solicitar os números.
2. Somar os números.
3. Apresentar o resultado.

Se a ordem for alterada, o algoritmo poderá apresentar erros ou resultados incorretos.

## Exercício 4 — O que pode acontecer quando um algoritmo contém instruções ambíguas?

Podem ocorrer interpretações diferentes, resultados inesperados e falhas durante o processamento.

**Exemplo de instrução ambígua:**

"Adicione um pouco de água."

Problema: quanto significa um pouco?

**Instrução clara:**

"Adicione 200 ml de água."

A segunda instrução é mais precisa e reduz a possibilidade de interpretações diferentes.
