4. Academic Structure

The program follows four levels:

1. Educational program: 24-month objectives.
2. Curriculum: academic subjects and learning content.
3. Weekly schedule: 104 weeks of structured learning.
4. Lessons: theory, exercises, laboratories, assessments, and projects.

5. Academic Methodology

Each subject will combine:

- Theoretical study.
- Practical exercises.
- Programming activities.
- Technical laboratories.
- Knowledge assessments.
- Technical English.
- Documentation and portfolio development.

6. Progress Management

Academic progress will be documented in the corresponding weekly directories.

The main README will be updated only when significant milestones or structural changes occur.
