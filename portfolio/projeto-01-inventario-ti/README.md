# Projeto 01 — Sistema de Inventário de Ativos de TI

## 1. Objetivo
Desenvolver um programa em Python para cadastrar
e apresentar informações de ativos de TI.

## 2. Tecnologias utilizadas
- Python
- Termux
- Nano
- Git

## 3. Funcionalidades
- Cadastro do nome do equipamento.
- Identificação do tipo de ativo.
- Registro do número de patrimônio.
- Identificação da localização.
- Identificação do responsável.
- Exibição da ficha do ativo.

## 4. Ambiente de desenvolvimento
Tablet Android utilizando Termux.

## 5. Execução

Entre na pasta src e execute:

python main.py

## 6. Status
Primeira versão funcional.

## 7. Validação de dados

O sistema verifica se os campos obrigatórios
foram preenchidos.

Foi utilizado:
- Estrutura condicional if/else.
- Operador lógico or.
- Método strip().

## 8. Testes realizados

- Cadastro com todos os campos preenchidos.
- Cadastro com todos os campos vazios.
- Cadastro com campo individual vazio.
- Verificação de execução sem erros.
