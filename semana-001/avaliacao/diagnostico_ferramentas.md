1. Objetivo da atividade
  A atividade teve como objetivo demonstrar conhecimentos práticos de organização de diretórios no ambiente Linux, criação de
arquivos, utilização do interpretador Python, entrada e saída de dados e execução de testes.
  Também buscou consolidar habilidades fundamentais para o desenvolvimento de atividades futuras em Ciência da Computação e 
Cibersegurança.

2. Ambiente e ferramentas utilizadas
  .Termux: ambiente de terminal Linux no Android.
  .Python: linguagem utilizada para desenvolver o programa.
  .Git: ferramenta de controle de versão.
  .Comandos Linux: cd, ls, mkdir e cat.

3. Procedimento realizado
Etapa 1 - Acessar o diretório principal do projeto: cd ~/cybersecurity. Em seguida, foi executado: ls. O comando permitiu
verificar a existência do diretório semana-1.

Etapa 2 - Criar a estrutura de avaliação: mkdir -p ~/cybersecurity/semana-1/avaliacao. Esse comando criou o diretório
avaliacao dentro da pasta correspondente à primeira semana de estudos.

Etapa 3 - Acessar o diretório de avaliação: cd ~/cybersecurity/semana-1/avaliacao.

Etapa 4 - Criar o programa Python: Foi utilizado o comando cat para criar o arquivo diagnostico.py. O programa apresenta 
uma mensagem inicial, solicita ao usuário o nome de uma ferrramenta estudada, armazena a resposta em uma variável e exibe 
o resultado.

Etapa 5 - Executar o programa: O arquivo foi executado utilizando python diasgostico.py. Foram realizados dois testes 
independentes, utilizando diferentes entradas.
