1. Fundamentos de Sistemas e Cibersegurança

1.1 O que é um sistema operacional (Operating System — OS)?

É o software principal de um sistema computacional. Ele gerencia o hardware, executa programas e permite que o usuário interaja com o dispositivo.

1.2 Para que serve um terminal?

Serve para controlar um computador ou ambiente de software executando comandos, em vez de depender apenas de cliques e menus da interface gráfica (GUI — Graphical User Interface).

- GUI: Interface Gráfica do Usuário.
- CLI: Interface de Linha de Comando.

1.3 O que é um endereço IP?

Um endereço IP (Internet Protocol Address) é um endereço numérico atribuído a uma interface de rede para identificá-la e permitir que os dados sejam encaminhados entre dispositivos em uma rede.

O IP permite identificar uma interface de rede no contexto da comunicação e encaminhar pacotes de dados.

1.4 O que é uma vulnerabilidade?

Uma vulnerabilidade (Vulnerability) é uma falha em um sistema, programa, rede ou configuração que pode ser explorada e comprometer a segurança.

Conceitos relacionados:

- Vulnerabilidade: É a falha.
- Ameaça (Threat): Algo capaz de causar dano. Um agente ou evento que representa uma possível ameaça.
- Exploração (Exploit): Técnica ou código que aproveita uma falha.
- Ataque (Attack): Ação que busca comprometer um sistema.

1.5 Qual é a diferença entre aprender um comando e compreender o que ele faz?

Aprender um comando é saber utilizá-lo. Compreendê-lo é saber o que ele faz, como funciona, quais são seus efeitos e quando é seguro utilizá-lo.

Um profissional competente não apenas memoriza comandos. Ele entende o que está fazendo e consegue resolver problemas mesmo quando encontra situações novas.

Se você compreende o comando, primeiro investigue:

1. O que ele executa?
2. Quais arquivos, processos ou recursos ele afeta?
3. Ele precisa de permissões especiais?
4. Pode causar danos ou expor informações?
5. Como posso verificar o resultado?

Essa postura é essencial tanto para quem trabalha com defesa (Blue Team) quanto para quem realiza testes de segurança autorizados (Red Team).

2. Exercícios e Respostas

Exercício 1 — O que o comando "pwd" pode informar?

Informa o caminho completo do diretório de trabalho atual (Present Working Directory). Ele mostra em qual diretório você está.

Exercício 2 — Qual é a função de "mkdir"?

O comando "mkdir" (Make Directory) serve para criar diretórios ou seja, pastas.

Exercício 3 — Por que registramos erros?

Porque erros identificam problemas, ajudam a encontrar suas causas, corrigir e testar novamente. Fazem parte do processo de aprendizagem e do trabalho profissional em tecnologia.

Na cibersegurança, registrar erros também ajuda a investigar incidentes, reconhecer padrões e evitar que o mesmo problema aconteça novamente.

Exercício 4 — Por que não devemos executar comandos desconhecidos como administrador ou com permissões elevadas sem entender seus efeitos?

Porque um comando malicioso ou incorreto pode causar danos graves ao sistema, comprometer dados e reduzir a segurança do dispositivo.

Exercício 5 — Explique o método de estudo em cinco etapas.

- Estudar: Compreender o conceito.
- Executar: Realizar a prática.
- Explicar: Descrever com suas próprias palavras.
- Testar: Modificar o exemplo e observar o resultado.
- Registrar: Guardar o código, as respostas e as dificuldades.

Crie e mantenha um diário de aprendizagem com três perguntas ao final de cada sessão:

1. O que aprendi?
2. O que consegui fazer sozinho?
3. O que ainda preciso revisar?

4. Shell e Bash

4.1 O que é Bash?

Bash é um shell (interpretador de comandos) que permite interagir com o sistema operacional digitando comandos em um terminal.

O nome Bash vem de Bourne Again SHell.

É muito utilizado no Linux, administração de sistemas, programação e cibersegurança.

Com ele, você pode:

- Automatizar tarefas repetitivas no Linux.
- Criar scripts para analisar arquivos e registros (logs).
- Administrar usuários, diretórios e permissões.
- Encontrar ferramentas para investigar problemas.
- Executar ferramentas de segurança em laboratórios autorizados.

4.2 O que é Shell Scripting?

Shell Scripting significa escrever scripts de Shell, ou seja, pequenos programas que automatizam tarefas por meio de comandos.

Ele permite integrar elementos fundamentais da programação:

- Variáveis.
- Condições.
- Repetições.
- Funções.
- Automação.

4.3 O que são permissões elevadas?

Normalmente, um usuário comum possui permissões limitadas sobre os arquivos e recursos do sistema.

Um administrador ou usuário com privilégios elevados pode realizar operações que um usuário comum não pode.

No Linux, o usuário "root" possui privilégios administrativos muito amplos.

Um profissional de segurança verifica a origem, analisa o comportamento e minimiza os privilégios (Least Privilege) e os riscos antes de executar códigos desconhecidos.
