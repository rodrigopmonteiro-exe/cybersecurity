# Aula 6 — Laboratório Integrado

## 1. Objetivo da aula

Integrar os conhecimentos adquiridos nas aulas anteriores
em um ambiente prático de laboratório.

Aplicar ferramentas, Python e comandos do Termux para
realizar tarefas relacionadas à análise e segurança
de arquivos.

## 2. Technical English

### 2.1 Vocabulário e frases técnicas

**1. I used a tool to analyze the files in the laboratory.**

Tradução:
Eu utilizei uma ferramenta para analisar os arquivos
no laboratório.

**2. I created a Python script to automate the security task.**

Tradução:
Eu criei um script Python para automatizar a tarefa
de segurança.

**3. I will execute the script in the Termux environment.**

Tradução:
Eu executarei o script no ambiente Termux.

**4. The output shows the results of the script execution.**

Tradução:
A saída apresenta os resultados da execução do script.

**5. I need to verify the results to ensure everything
works correctly.**

Tradução:
Preciso verificar os resultados para garantir que tudo
funcione corretamente.

## 4. Fluxo de trabalho do laboratório

Com base nas frases estudadas, podemos representar
o fluxo de trabalho da seguinte maneira:

1. Selecionar uma ferramenta para análise.
2. Analisar os arquivos do laboratório.
3. Criar um script Python para automatizar uma tarefa.
4. Executar o script no ambiente Termux.
5. Observar a saída (output).
6. Verificar os resultados.
7. Confirmar se tudo funciona corretamente.

---

## 5. Competências trabalhadas

- Utilização de ferramentas de análise.
- Organização de arquivos.
- Programação em Python.
- Automação de tarefas de segurança.
- Execução de scripts no Termux.
- Interpretação de resultados.
- Verificação e validação de resultados.
- Inglês técnico aplicado à cibersegurança.

## 6. Revisão da aula

Nesta aula, o foco é integrar conhecimentos anteriores
em um ambiente prático.

Conceitos importantes:

- Tool = Ferramenta.
- Script = Código executável.
- Execute = Executar.
- Output = Saída.
- Verify = Verificar.
- Security Task = Tarefa de segurança.

**Objetivo:**

Desenvolver a capacidade de utilizar ferramentas,
criar scripts em Python, executar tarefas no Termux
e verificar os resultados obtidos.
