# Laboratório Integrado - Aula 6

## Objetivo
Criar um inventário simples de ferramentas usando Python.

## Requisitos
- Termux
- Python 3
- Git
- Arquivo inventario.py

## Como executar
python inventario.py

## Funcionamento
O programa utiliza uma lista para armazenar ferramentas, um laço for para percorrer os elementos e
uma condição if/else para verificar se a lista está vazia.

## Testes realizados
1. Lista com três ferramentas.
2. Lista vazia.
3. Verificação a quantidade de ferramentas.
4. Verificação do hash SHA-256.

## Integridade
Comando utilizado:
sha256sum inventario.py

## Limitações
O inventário é estático e não identifica automaticamente as ferramentas instaladas no dispositivo.
