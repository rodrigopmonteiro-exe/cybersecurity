## Parte B — Avaliação prática (55 min)

Execute o desafio sem copiar os comandos prontos das aulas anteriores.

### Desafio: ambiente de laboratório

Você deverá criar um pequeno projeto que documente seu ambiente de estudo e demonstre o uso básico de Python.

#### Requisitos obrigatórios

- [ ] Criar a pasta `~/cybersecurity/semana-01/avaliacao`.
- [ ] Criar um arquivo Python chamado `diagnostico.py`.
- [ ] Exibir o título `Cybersecurity Lab`.
- [ ] Receber do usuário o nome de uma ferramenta estudada.
- [ ] Exibir a ferramenta informada e uma mensagem de conclusão.
- [ ] Executar o programa e registrar sua saída.
- [ ] Criar `relatorio-final.md` explicando o procedimento e os resultados.
- [ ] Registrar uma dificuldade encontrada e como você a resolveu.

#### Modelo inicial opcional

```python
print("Cybersecurity Lab")

ferramenta = input("Nome da ferramenta estudada: ")

print("Ferramenta:", ferramenta)
print("Diagnóstico concluído.")
```

Execute o arquivo com:

```bash
python diagnostico.py
```

Teste pelo menos duas entradas diferentes.
